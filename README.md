# 栖居 AI 家具服务站 · 手机测试镜像

本仓库包含顾客端页面、32 件演示商品数据，以及 `api-server.mjs` 火山方舟服务端代理；不包含 API 密钥或原本机数据库。GitHub Pages 仅托管前端，模型请求由独立服务端完成，密钥不会发送到浏览器。

本机启动：在项目根目录的 `.env` 配置 `ARK_API_KEY`、`ARK_MODEL`、`ARK_BASE_URL`，然后运行 `node api-server.mjs`；默认监听 `127.0.0.1:4185`。访问 `/api/health` 检查服务状态。公开演示需要保持该服务与专用 HTTPS 隧道在线。

聊天记录仅在当前页面内存中维护。刷新页面或点击「清空对话」都会删除旧对话；收藏、购物袋和体验订单仍单独保存在本地浏览器。

所有下单、物流及售后记录均为浏览器本地模拟。
